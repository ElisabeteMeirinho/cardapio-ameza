# Checklist do piloto AMEZA

## Configuração
- [ ] Projeto Firebase exclusivo da AMEZA criado.
- [ ] `config.js` preenchido com os dados do app Web correto.
- [ ] Authentication e-mail/senha ativado.
- [ ] Domínio de hospedagem autorizado no Firebase.
- [ ] Regras do Firestore revisadas e publicadas no projeto correto.
- [ ] Conta administradora cadastrada manualmente em `platformAdmins`.

## Testes com dados fictícios
- [ ] Criar conta de estabelecimento e confirmar e-mail.
- [ ] Enviar solicitação de parceria.
- [ ] Administrador aprova e ativa perfil público.
- [ ] Restaurante entra no painel.
- [ ] Cadastrar, editar, ocultar, publicar e excluir um prato.
- [ ] Prato aparece somente quando publicado.
- [ ] Restaurante aparece no catálogo enquanto ativo.
- [ ] Página pública individual abre pelo link.
- [ ] QR Code direciona ao cardápio individual.
- [ ] WhatsApp abre com o contato comercial correto.
- [ ] Filtros distinguem sem leite, sem lactose e sem glúten.
- [ ] Suspensão retira o restaurante e os pratos do catálogo.

## Antes do piloto real
- [ ] Política de privacidade e retenção revisadas.
- [ ] Contatos publicados conferidos com os restaurantes.
- [ ] Declarações de ingredientes, alergênicos e contato cruzado revisadas.
- [ ] Nenhuma informação é apresentada como certificação sanitária.
- [ ] Cobrança manual e condições comerciais explicadas fora da plataforma.
