# AMEZA — cardápios digitais inclusivos

Plataforma independente do movimento Inclusão Alimentar.

## MVP planejado
- Catálogo público de estabelecimentos aprovados.
- Página pública individual por restaurante.
- Painel autenticado para cadastro, edição, rascunho e publicação de pratos.
- Declarações separadas: sem leite e derivados, sem lactose e sem glúten.
- Link público, QR Code e contato pelo WhatsApp.
- Painel administrativo para aprovação e suspensão de parceiros.

## Antes de ativar
Este repositório deve usar um **projeto Firebase exclusivo da AMEZA**. Não reutilize o Firebase institucional de Inclusão Alimentar. O arquivo `config.js` contém marcadores até que o projeto próprio seja criado e configurado.

Consulte `INSTRUCOES-FIREBASE.md` e `CHECKLIST-PILOTO.md`.
